# Casillas de Peones Camineros - datos del mapa

Contenido:
- `casillas_peones_camineros.js`: datos listos para cargar desde Jimdo con `<script src="..."></script>`.
- `casillas_peones_camineros.geojson`: copia GeoJSON para otros visores o futuras herramientas.
- `index.html`: página de prueba. Al publicarla con GitHub Pages debe mostrar el número de casillas cargadas.

## Publicar con GitHub Pages

1. Crea un repositorio público llamado `casillas-mapa`.
2. Sube los tres archivos a la raíz del repositorio.
3. En GitHub: Settings -> Pages.
4. En "Build and deployment", selecciona "Deploy from a branch".
5. Branch: `main`, carpeta: `/ (root)`.
6. Guarda y espera a que GitHub publique la página.

La dirección de prueba será aproximadamente:
`https://TU_USUARIO.github.io/casillas-mapa/`

Y el archivo que usará Jimdo:
`https://TU_USUARIO.github.io/casillas-mapa/casillas_peones_camineros.js`

## Importante

Para actualizar más adelante, sustituye el archivo
`casillas_peones_camineros.js` por la nueva versión manteniendo exactamente el mismo nombre.
Jimdo seguirá usando la misma URL.
